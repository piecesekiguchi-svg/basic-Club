## キャッチコピー候補10案（参考）

| # | コピー | 狙い |
|---|---|---|
| 1 | 「なんとなく切る」を、今日で終わりにする。 | 悩み「なんとなくやっている」を直接言葉にして、変わるきっかけを作る |
| 2 | ベーシックは、一生ものだ。 | ベネフィット「一生物のスキル」を短く強く言い切る。B案向き |
| 3 | 速く、美しく、疲れない。カットの土台を、もう一度。 | 得られる3つの変化を一行で並べて伝える |
| 4 | 教わる機会がなかった人へ。ベーシックを、1から。 | 「教えてくれる人がいない」層に、自分のことだと気づいてもらう |

## 申込につながりにくい点と対応

| 問題点 | 対応 |
|---|---|
| 申込方法が「LINEで『ベーシック』と送る」で、操作が分かりにくく離脱しやすい | 3ステップの図解と「ベーシック」のコピーボタンを設置。すべてのボタンにも「『ベーシック』と送って申し込む」と明記 |
| スマホでは読んでいる途中に申込ボタンが見えない時間が長い | 画面下に追従ボタンを設置（ファーストビューと最後の申込エリアでは自動で隠れる）。ボタンは計6か所 |
| ¥66,000が高く感じられやすい | 「1回あたり¥11,000」「分割払いOK」を価格のすぐ近くに表示 |
| 急いで申し込む理由がない | 「定員10名」を各所に表示。残席・申込締切の枠を用意（現在【要確認】） |
| 受講者の声・カリキュラムが空欄で、判断材料が足りない | 申込を最も左右する部分なので枠とBefore/After写真枠を用意。内容は【要確認】 |
| 講師が2名（関口裕樹・ヤマグチ ヒロム） | 2名分のプロフィールを掲載。ヤマグチ氏の漢字表記は【要確認】 |
| 欠席時の振替・持ち物・ウィッグ代・キャンセル規定が分からない | 申込前の不安になりやすいため、FAQ・開催概要に【要確認】の枠を用意 |
| 「得られること」は3つと書かれているが、実際は4つある | 4つすべて掲載。3つに絞るかどうか要確認 |
